# Lumincoin Finance

## О проекте

Lumincoin Finance - веб-приложение для учёта личных финансов, позволяющее отслеживать доходы и расходы, управлять категориями операций и контролировать текущий баланс.

Приложение предоставляет инструменты для анализа финансовой статистики, данные о доходах и расходах отображаются в виде диаграмм с возможностью фильтрации по различным временным периодам. Для работы с пользователями и финансовыми операциями используется собственный REST API.

## Функциональность

- **Регистрация и авторизация:** создание аккаунта и вход в систему с использованием электронной почты и пароля.
- **Управление доходами и расходами:** создание, просмотр, редактирование и удаление финансовых операций.
- **Управление категориями:** добавление, редактирование и удаление пользовательских категорий доходов и расходов.
- **Контроль баланса:** отображение текущего баланса и его автоматический пересчёт при изменении финансовых операций.
- **Финансовая статистика:** визуализация доходов и расходов с помощью круговых диаграмм.
- **Фильтрация по периодам:** просмотр операций за текущий день, неделю, месяц, год, за всё время или выбранный интервал дат.
- **Защита пользовательских данных:** хеширование паролей, JWT-аутентификация и обновление токенов доступа.

## Запуск проекта

Для локального запуска потребуется установленный Node.js и npm.

### 1. Клонирование репозитория

```bash
git clone https://github.com/Kryanrd/lumincoin-finance.git
cd lumincoin-finance
```

### 2. Запуск Backend

В первом терминале перейдите в папку `backendp`:

```bash
cd backendp
```

Установите зависимости:

```bash
npm install
```

Запустите сервер:

```bash
npm start
```

Backend будет доступен по адресу:

`http://localhost:3000`

### 3. Запуск Frontend

Откройте второй терминал в корневой папке проекта и перейдите в `frontend`:

```bash
cd frontend
```

Установите зависимости:

```bash
npm install
```

Запустите приложение в режиме разработки:

```bash
npm run dev
```

Frontend будет доступен по адресу:

`http://localhost:9000`

Для корректной работы приложения необходимо одновременно запустить frontend и backend.
